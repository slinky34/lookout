For a machine that isn't in Portainer. (Machines in Portainer show up on their own once Portainer is connected in Settings.) That machine needs a read-only Docker API, which the snippet below sets up.

Set up the other machine (one-time)

Deploy this stack on that machine. It exposes only read access to containers and images, on port 2375. Use it only on your home network.

services:
  docker-proxy:
    image: ghcr.io/tecnativa/docker-socket-proxy:latest
    container_name: docker-proxy
    restart: unless-stopped
    environment:
      CONTAINERS: 1
      IMAGES: 1
    volumes:
      - /var/run/docker.sock:/var/run/docker.sock:ro
    ports:
      - "2375:2375"
